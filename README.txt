Palmetto Staffing live Airtable job cards - SAFE VERSION

This version does not use Airtable filter/sort query parameters.
It pulls records from the Open Jobs table, then filters Status = Open inside the Netlify function.

Required Netlify environment variables:
AIRTABLE_TOKEN = your Airtable personal access token
AIRTABLE_BASE_ID = appsKMryvnmEAehrM
AIRTABLE_TABLE_NAME = Open Jobs

AIRTABLE_VIEW_NAME is not needed.
